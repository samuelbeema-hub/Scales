🎸 Chordzilla

The Ultimate Scale & Chord Finder for Musicians

Chordzilla is a modern music theory web app designed for musicians, worship teams, guitarists, keyboard players, beginners, and music learners who want quick access to scales, chords, and pentatonic patterns in one place.

This project helps users instantly discover:

- Major scales
- Minor scales
- Sharp (#) scales
- Flat (b) scales
- Pentatonic scales
- Chords inside every scale
- Relative scales
- Scale notes and moods

Built with pure HTML, CSS, and JavaScript, Chordzilla is lightweight, responsive, and easy to use on both desktop and mobile devices.
